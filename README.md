# 🎮 Tic-Tac-Toe Game

A modern, web-based Tic-Tac-Toe game built with **HTML, CSS, and JavaScript**. The application features an interactive UI, neon glow accents, smooth gameplay mechanics, and full responsiveness across mobile and desktop devices.

🌐 **Live Demo:** [https://tic-toc-toe-game-y.netlify.app/](https://tic-toc-toe-game-y.netlify.app/)

---

## ✨ Features

- 🎯 **Interactive Gameplay:** Classic two-player Tic-Tac-Toe logic (`X` vs `O`).
- 🎨 **Modern Neon UI:** Glowing visual effects on a dark futuristic theme.
- 📱 **Fully Responsive:** Perfectly aligned 3-column layout on mobile, tablet, and desktop screens.
- ⚡ **Lightweight & Fast:** Pure Vanilla JavaScript without any external libraries or frameworks.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and board layout structure.
- **CSS3:** Custom styling, Flexbox/Grid centering, neon glow effects, and media queries.
- **JavaScript (ES6):** Turn management, click events, and winning condition evaluations.
